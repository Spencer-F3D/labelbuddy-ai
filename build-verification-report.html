四、怎麼跑起來

  • npm install → npm run build → npm start（node dist/server.cjs，預設 http://localhost:3000）
  • 開發：npm run dev
  • 雲端 Gemini（選用）：.env 設 GEMINI_API_KEY；未設自動走本機「智慧守護引擎」。
