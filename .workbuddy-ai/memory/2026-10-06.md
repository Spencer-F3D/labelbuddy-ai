### 症狀

### ★★ 真正的原因（比前兩輪的判斷都精確）
`.row-problem { flex: 1 1 0; min-height: 0 }` ——
**`min-height: 0` 讓這一列可以被壓到比內容還矮**；

★ 教訓：**改任何一列的 flex 份額後，兩列都要重新驗邊界**，不能只驗剛改的那一列。

### 修法
| 項目 | 改動 |
| --- | --- |
| 根因 | `.row-problem` 與 `.cards` **移除 `min-height: 0`**（並加註解說明不可加回） |

```python
x = int(31*mm); col = a[:, x]
white = (col[:,0]>246)&(col[:,1]>246)&(col[:,2]>246)   # 找白卡區段
for (s, e) in runs:
    band = lum[int((e/mm+0.8)*mm):int((e/mm+7.0)*mm), int(26*mm):int(774*mm)]
    print((band<150).mean()*100)     # >0.3% = 有東西疊上去了
```

結果：5 個列邊界**全部 0.00–0.01%** ✅

## 21:04 修正 SDG 徽章「3」穿出框框

### 症狀
Spencer 截圖：綠色徽章的「3」被上緣切掉。

### ★★ 根因（不是字太大，是盒子寫死高度）
```css
.sdg-badge { width: 34mm; height: 34mm; justify-content: flex-end; padding: 2.6mm 3.4mm; }
```
內容（16mm 數字 ＋ 標籤）約 **41mm** > 盒子的 34mm →
`justify-content: flex-end` 讓**多出來的部分往「上」溢出** → 數字被上緣切掉。

| --- | --- | --- |

| radius / padding | 6.5mm / 2.6,3.4mm | 7mm / 3.2,3.6mm |
| `.n` | 16mm | **17mm** |
| `.t` | 4.3mm / lh 1.15 | **4.1mm / lh 1.2** |

★ 同時**加寬**才對 —— 內寬 42−7.2 = 34.8mm 足以讓「& WELL-BEING」成一行，
標籤回到 2 行，內容高度才降得下來。**只加 min-height 而不加寬，標籤仍會多折行。**
