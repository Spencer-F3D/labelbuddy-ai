## 21:00 語音完全沒聲音（真因）＋ 語音設定 ＋ 成份表範例 ＋ 開發者面板（commit 02cfdb0）

### ★★ 語音沒聲音：不是音量，是**沒有發聲管道**
使用者說「語音功能用不到，完成識別後沒有聲音，按按鈕也沒有聲音」。

**根因**：`speakText()` 只用瀏覽器的 Web Speech API。
但 APK 是 **Capacitor 的 Android WebView**，而
**Android WebView 不實作 Web Speech 合成 API**（那是 Chrome 瀏覽器才有）。
→ 每次都走進第一個 `if (!('speechSynthesis' in window)) return false;`
→ **靜默回傳 false：不拋錯、不記錄、畫面無異狀**。

**修法**：`@capacitor-community/text-to-speech@8` → 原生走 Android TextToSpeech，
瀏覽器仍走 Web Speech（兩邊都要有聲音：電腦展示 vs 決賽手機）。

★★ **只裝 npm 套件不夠，要驗三件事才算真的生效**：
  ① `android/app/capacitor.build.gradle` 要有
     `implementation project(':capacitor-community-text-to-speech')`（cap sync 產生）
  ② APK 內 `assets/capacitor.plugins.json` 要有
     `com.getcapacitor.community.tts.TextToSpeechPlugin`
  ③ **合併後的 AndroidManifest 要有 `<queries><intent><action TTS_SERVICE>`**
     —— Android 11+ 的套件可見性限制，少了它 TTS 引擎**找不到且不會報錯**。
     這一條外掛自己的 manifest 有帶，靠 manifest merger 合併進來。
  → 驗證方式：`aapt2 dump xmltree --file AndroidManifest.xml <apk>`

★ 另外修掉兩個既有問題：
  - `getVoices()` 是**非同步**的，第一次呼叫常回空陣列 → 舊版第一次朗讀
    永遠挑不到語音（「第一次沒聲音」的難重現症狀）→ 現在監聽 `voiceschanged`。
  - 找不到語音時 lang 設成 `zh-TW`；使用者在澳門，應為 `zh-HK`（粵語）。
