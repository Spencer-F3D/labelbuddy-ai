## B. TTS「線上網站沒有聲音」

### 診斷（新增 `scripts/probe-tts-voices.mjs`）
實測本機 Chrome 與 Edge：**都有 zh-HK，speak 都正常**（onstart 490ms／713ms）。
→ 「找不到語音」那條路徑在**這台機器不成立**。

**關鍵觀察**：兩台瀏覽器上唯一的**中文粵語語音都是「網路語音」**（`localService: false`，
Chrome = `Google 粤語（香港）`、Edge = `Microsoft 曉曼 Online`）。
本機語音只有 zh-TW。→ 網路不通時粵語就完全沒聲音。

### 三條「靜默失敗」路徑（全部符合「按了沒反應、零錯誤」）
1. **非長者身分預設音量 0**（`ttsSettings.ts`）→ `speakText` 第一關 `return false`。
   且音量 0 時設定頁的試聽與診斷區塊**全部靜默跳過**。
   ★ 使用者說的「有聲音顯示沒有」很可能就是設定頁那行「目前沒有聲音」——
   而他調的是**手機／系統音量**。→ 文案改成「**App 的朗讀音量是 0**」＋
   「和手機音量是分開的」。
2. **找不到語音 → 靜默 no-op**：`speak()` 不觸發 `onstart` 也不觸發 `onerror`。
3. **`outcome:'no-voice'` 是死值**：型別有、UI 有分支、**沒有生產者** →
   UI 落到 else 顯示「沒有送出」（實際 `sent:true`，訊息是錯的）。

### 修法
- `src/utils/tts.ts`：`voice === null` → `outcome:'no-voice'`；
  新增 `'silent'` 型別值 ＋ **1500ms watchdog**（沒 onstart 就標記）。
  ★ 門檻用 1500ms 不是 800ms —— 實測網路語音 onstart 490／713ms，800ms 會誤報。
- `src/components/TtsSettingsSection.tsx`：新增獨立 **`#tts-test-voice`** 按鈕；
  音量 0 按下 → 說出原因；診斷區塊條件由 `played && isOn && deviceCanSpeak`
  改為 `played && deviceCanSpeak`（**音量 0 也要看得到原因**）；
  ★ 修掉 `TtsVoiceLangSection` 的**掛載時快照 bug**（在上面拉音量後選語言仍讀到舊的 0）。
- `src/App.tsx`：`handleToggleSpeakSummary` **要看 `speakText` 的回傳值** ——
  舊版無條件 `setIsSpeaking(true)`，按鈕變成「停止朗讀」卻一個字都沒唸。
  新增 `ttsNotice` 狀態＋結果頁可見提示（含 1.8s 後讀 `'silent'`）。
- 新增 `scripts/check-tts-diagnostic.ts`（`npm run check:tts`）：43 通過 / 0 失敗 / 1 跳過。
  含「outcome 每個值都要有生產者」這條紅線的機械檢查。
