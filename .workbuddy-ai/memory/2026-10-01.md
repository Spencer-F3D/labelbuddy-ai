### ★ 1a 的根因值得記下來

```ts
// 原本的註解寫著：
// ⚠️ 日期也跟隨標籤語言，否則會出現「中文品名 ＋ 英文日期」的混雜
dateString: formatScanTime(labelLanguage, new Date()),
```

**它是刻意寫的**，不是手誤。但那個理由把兩件不同性質的事混在一起：
- 紀錄的**內容**（品名、說明）→ 屬於標籤 → 跟標籤語言 ✅
- 紀錄的**時間**（幾月幾日幾點）→ 屬於**使用者** → 該跟介面語言

★ 這是 09-29「紀錄跟隨標籤語言」那個決定的**副作用**：
  規則本身沒錯，是**適用範圍多了一個欄位**。

### ★ 1d 的根因不是種子資料，是這一行

```ts
if (Array.isArray(parsed) && parsed.length > 0) return parsed;
```

使用者按「清除所有資料」→ 存進 `"[]"` → 重新載入讀到空陣列 →
判定「沒存過」→ **重新種入 6 筆假紀錄**。
→ 改成 `Array.isArray(parsed)`（空陣列是**有效資料**）。

### ★ 附帶發現：0 筆紀錄卻顯示「Grade A (Excellent)」

`const score = total > 0 ? … : 85` —— 0 筆直接拿 85 分。
那是「一定有 6 筆示範資料」年代的假設，移除示範資料後才浮現。
→ 沒有資料就不顯示評級（畫面與匯出報告都不印）。

## ⚠️⚠️ 抓到一個更嚴重的問題：檢查腳本的「假通過」

**這是本輪最重要的發現。**

開發伺服器在檢查途中死掉（`dist/index.html` 尚未寫入就啟動），
之後每一頁都變成**瀏覽器的英文錯誤頁** →
CJK 掃描掃不到中文 → **回報「0 處中文」並 EXIT 0**。

但實際上 13 個畫面**全部沒驗到**，而且每一項「找不到選單項目」「找不到區塊」
都只印 ⚠️ 警告、**不影響 exit code** —— 所以失敗看起來像成功。

**已加兩道防護**：
1. 導覽後確認 `#root` 真的有渲染內容、且 origin 正確，否則重試 8 次後中止
2. 載入失敗直接 `process.exit(3)`

★ 教訓：**「找不到東西」不該只是警告。** 檢查腳本裡每一個
  「找不到 X」都應該問一次：「如果永遠找不到，這份報告還有意義嗎？」

★ 另一個踩到的細節：`localStorage` 在代理的 502 錯誤頁上會丟
  `SecurityError: Access is denied` —— 所以**碰 localStorage 之前要先確認載入成功**。

## APK 打包（從零開始）

### 環境盤點（證實了先前的判斷）
- ❌ 沒有 Java、❌ 沒有 Android SDK、❌ 沒有 Gradle
- ✅ 有 `winget`｜C 槽 61 GB、D 槽 191 GB 可用

### 建置過程
1. `winget install Microsoft.OpenJDK.17` → `C:/Program Files\Microsoft\jdk-17.0.20.101-hotspot`
2. 下載 Android command-line tools（153 MB）→ 解壓到 `D:/Android/Sdk/cmdline-tools/latest/`
   ⚠️ 解壓後結構是 `cmdline-tools/bin`，但 Android 要求 `cmdline-tools/latest/bin` —— 要手動搬
3. `sdkmanager` 接受授權並安裝 `platform-tools`／`platforms;android-34`／`build-tools;34.0.0`
4. `npm install @capacitor/core @capacitor/cli @capacitor/android`
5. 建立 `capacitor.config.ts`
6. `npx cap add android`

### ★ 關鍵設計決定：把網頁打包進去，不用 `server.url`

| 做法 | 優點 | 缺點 |
| --- | --- | --- |
| `server.url` 指向線上網站 | 零改動、永遠最新 | 沒網路就打不開；看起來像瀏覽器外殼 |
| **打包 `dist/`（採用）** | 秒開；離線可用；**「只在本機」的承諾才成立** | 需要處理 API 絕對網址 |

★ 決定性理由：本專案的「只在本機」模式承諾**完全不連網**。
  如果連介面都要從網路載入，那個承諾根本不可能成立。

### ★ 連帶的程式改動：`src/utils/apiBase.ts`

Capacitor 的 WebView origin 是 `https://localhost`，
所以 `fetch('/api/...')` 會打到 **localhost** → 連不上（而且是**靜默失敗**，
看起來像「伺服器壞了」而不是「網址錯了」）。

→ 新增 `apiUrl()`：偵測到 Capacitor 就用絕對網址，否則用相對路徑。
→ 4 處 API 呼叫全部改用它。
→ 用**執行時偵測**而不是建置時環境變數 —— 避免「忘了用對的參數打包」。

★ 好消息：`worker.ts` **早就設好 CORS**（`Access-Control-Allow-Origin: *`），
  註解還寫著「讓 Capacitor 打包的 APK 能跨來源呼叫」。

### AndroidManifest 權限
- `CAMERA`（`<input capture>` 用）—— 沒宣告會**靜默失敗**
- `READ_MEDIA_IMAGES`（Android 13+ 相簿）
- `READ_EXTERNAL_STORAGE`（maxSdkVersion 32）
- `<uses-feature camera required="false">` —— 設 required 會讓沒相機的裝置裝不了

### 版控
- `android/` **要進版控**（是原始碼）
- 忽略：`.gradle/`、`local.properties`、`assets/public/`（cap sync 產生）
- ⚠️ `*.jks` / `*.keystore` **絕對不可進版控**（外洩等於別人能冒名發布）
