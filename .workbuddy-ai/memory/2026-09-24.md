## 架構關鍵發現
前端 `fetch('/api/analyze-label')` 用**相對路徑**，且 **API 金鑰只存在後端**。
→ **純離線 APK 會讓雲端辨識完全失效**。APK 必須指向某個後端。

| 場景 | 後端 API | 相機 | 結果 |
| --- | --- | --- | --- |
| 電腦瀏覽器 localhost:3000 | ✅ 同源 | ✅ | ✅ 完美 |
| 手機連區網 IP | ✅ | ❌ 非 HTTPS 被擋 | ⚠️ 只能上傳圖片 |
| 純離線 APK | ❌ | — | ❌ 雲端辨識全掛 |

## Capacitor 規格調查（實查官方 repo）

- Android template：`minSdk 24`、`compileSdk 36`、`targetSdk 36`

- 官方要求：Node 22+、Android Studio 2025.2.1+、SDK Platform API 24+

## GitHub 做後端的三方案

4. **金鑰安全** → 必須存環境變數，不進 Git
